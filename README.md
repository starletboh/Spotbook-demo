# Spotbook Demo



This repository contains a static demonstration version of Spotbook.

Spotbook is a venue operations platform designed for businesses that manage reservations and physical spaces, including restaurants, bars, beach bars, clubs, hotels, event venues, and similar hospitality businesses.

The platform is intended for internal staff use. Reservations are managed by employees and management teams rather than customers, providing a centralized place to organize reservations, customer information, venue resources, and operational notes.

## About This Demo

This version has been created for demonstration and presentation purposes only.

The original application includes:

* Backend services
* Database integration
* Authentication
* Role-based access control
* API endpoints
* Business logic
* Analytics and reporting

To make deployment simple and allow hosting on GitHub Pages, all backend functionality has been removed from this demo.

The application now uses static mock data to showcase the user interface and workflows.

## Features Demonstrated

* Dashboard overview
* Reservation management
* Customer records
* Internal notes
* Interactive venue/floor management
* User management
* Role management
* Activity logs
* Analytics and reporting screens

All data displayed in the demo is fictional and provided for demonstration purposes only.

## Technology

This demo is built using static frontend assets only:

* HTML
* CSS
* JavaScript

No backend, database, or external services are required.

## Deployment

The project can be hosted directly on GitHub Pages or any static hosting provider.

Simply serve the repository contents as static files.

## Disclaimer

This repository is a demonstration build of Spotbook and does not represent the full production application. Functionality that depends on backend services has been replaced with mock data and frontend-only interactions.
